## How to Choose a GSI

- **GMS vs Vanilla**: GMS includes Google Play Services for apps and updates, Vanilla is pure Android
- **Architecture**: ARM64-AB/ARM64-B (64-bit modern), x86_64 (rare), ARM32-BINDER64 (for devices with >3GB RAM)
- **QPR**: Quarterly Platform Release - security updates and improvements
- **Maintainer**: Different projects offer different customizations; Google GSI is the official baseline
